## Store Listing

**Extension Name**
Cheese Wallet

**Short Description**
Premium EVM-compatible browser wallet for the Cheese Blockchain. Instantly connect to DEX and DApps.

**Detailed Description**
Cheese Wallet is the official browser extension for interacting with the Cheese Blockchain. It brings secure key management and standard Web3 wallet connectivity directly to your browser popup.

Features:
- Secure seed phrase generation (BIP-39 standard).
- Encrypted keystore storage using standard EVM standards.
- Instant balance checks for NCH and portfolio tokens.
- Secure message signing and transaction execution interface.
- Automatic EIP-1193 injected provider to hook up to DApps (like Cheese DEX).

How to use:
1. Pin the extension to your toolbar.
2. Click the icon and select "Create New Wallet" to generate a recovery phrase, or "Import Seed Phrase" to restore an existing account.
3. Establish a lock password.
4. Navigate to any Cheese Blockchain decentralized app and click "Connect Wallet" to request standard authorization!
