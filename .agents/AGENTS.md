Before running any `git push` or deployment:
1. **Verify GitHub CLI Account**: Must use `@cryptoexdevcheese`.
   `env -u GITHUB_TOKEN gh auth switch --user cryptoexdevcheese`
2. **Verify Remote URL**: Must be `https://github.com/cryptoexdevcheese/cheese-blockchain.git`.
3. **Verify Branch**: `master`.
4. **Verify Production URL**: `https://cheeseblockchain.com/`.
